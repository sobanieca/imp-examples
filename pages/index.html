imp examples

Live demos of apps built with imp. The source of each one is in sobanieca/imp-examples.

  • Beacon - a Grafana-like SPA: shell, router, guards, forms, dialogs and translations. A fake API in the page stands in for the backend: sign in with any email and the password admin.
  • Brickfall - a brick breaker game on a canvas, as a PWA that installs and plays offline.

The shop example renders on the server with Node.js, so it is not hosted here. Run it locally.
