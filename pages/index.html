imp examples

Live demos of apps built with imp. The source of each one is in sobanieca/imp-examples.

  • Beacon - a Grafana-like SPA: shell, router, guards, forms, dialogs and translations. The hosted build has no backend, so sign-in does not succeed here. Run it locally with imp start to use the mocked API.
  • Brickfall - a brick breaker game on a canvas, as a PWA that installs and plays offline.

The shop example renders on the server with Deno, so it is not hosted here. Run it locally.
