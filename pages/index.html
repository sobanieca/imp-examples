Apps built with imp.

Three complete apps in plain JavaScript, with no build config and no framework other than imp. Open the live demos, or read the source on GitHub.

  • Get imp
  • Source on GitHub

  • Beacon

    observability SPA

    A Grafana-like app with dashboards, panels and sources: shell, router, guards, forms, charts, tables, dialogs and translations.

    A fake API in the page stands in for the backend. Sign in with any email and the password admin. Changes last until the page reloads.

    • Open the demo
    • Source

  • Brickfall

    PWA game

    A brick breaker game on a canvas. One imp.json block makes it a PWA: manifest, icon set, offline service worker and install prompt.

    Install it from the browser, and it plays offline.

    • Play the game
    • Source

  • Impulse

    server-rendered shop

    A shop that Hono renders on Node.js. imp components run as islands in the HTML: the cart, the add-to-cart buttons and the notification center.

    It needs a server, so it has no live demo. Run it locally with Node.js 22 or later: npm install && npm run dev, then open localhost:8000.
